## 🎯 À propos

TapHair est une application innovante qui connecte les clients avec des coiffeurs professionnels pour des services de coiffure à domicile ou en salon. Notre plateforme simplifie le processus de réservation et offre une expérience utilisateur fluide et intuitive.

## 🚀 Fonctionnalités

- **Réservation simplifiée** : Processus de réservation en plusieurs étapes faciles à suivre
- **Double mode** : Services disponibles à domicile ou en salon
- **Gestion des rendez-vous** : Suivi des réservations en temps réel
- **Paiement sécurisé** : Intégration de solutions de paiement fiables
- **Interface intuitive** : Design moderne et responsive

## 🛠 Technologies utilisées

- **Frontend** :
  - React.js avec TypeScript
  - Redux pour la gestion d'état
  - Tailwind CSS pour le style
  - React Router pour la navigation
  - date-fns pour la gestion des dates

- **Backend** (en développement) :
  - Node.js
  - Express.js
  - Base de données (à définir)

## 📦 Installation

1. Clonez le dépôt :
```bash
git clone https://github.com/DjennadRany/HairTap.git
```

2. Installez les dépendances :
```bash
cd front
npm install
```

3. Lancez l'application en mode développement :
```bash
npm run dev
```

## 🔧 Configuration

1. Créez un fichier `.env` dans le dossier `front` :
```env
VITE_API_URL=http://localhost:3001
```
