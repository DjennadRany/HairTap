## 🔍 ANALYSE DES MODÈLES EXISTANTS

### ✅ MODÈLES DÉJÀ CRÉÉS ET OPTIMISÉS

#### 1. **User.js** - Modèle utilisateur principal
**Champs existants:**
- `_id`: ObjectId (clé primaire)
- `name`: String (nom complet)
- `email`: String (email unique)
- `password`: String (hashé)
- `role`: String (enum: 'user', 'coiffeur', 'admin')
- `phone`: String (téléphone)
- `bio`: String (biographie)
- `photo`: String (chemin photo)
- `addresses`: Object structuré
  - `home`: Object (adresse domicile)
    - `streetNumber`: String
    - `street`: String
    - `postalCode`: String
    - `city`: String
    - `floor`: String
    - `apartment`: String
    - `buildingCode`: String
    - `additionalInfo`: String
    - `coordinates`: Object {lat: Number, lng: Number}
  - `office`: Object (adresse bureau)
    - (même structure que home)
- `preferences`: Object structuré
  - `notifications`: Object
    - `email`: Boolean
    - `sms`: Boolean
    - `push`: Boolean
    - `marketing`: Boolean
    - `updates`: Boolean
  - `language`: String (enum: 'fr', 'en')
  - `theme`: String (enum: 'light', 'dark')
  - `timezone`: String
  - `currency`: String
  - `privacy`: Object
    - `showAddress`: Boolean
    - `showPhone`: Boolean
    - `showEmail`: Boolean

**Champs spécifiques coiffeur:**
- `speciality`: String (UNE SEULE spécialité - LIMITATION)
- `rating`: Number (note moyenne)
- `workingMode`: String (enum: 'salon', 'domicile', 'both')
- `travelRadius`: Number (rayon de déplacement en km)
- `workingHours`: Object (horaires de travail - STRUCTURE SIMPLE)
- `formation`: String (formation professionnelle)
- `RIB`: String (RIB bancaire)
- `yearsExperience`: Number (années d'expérience)

**Index existants:**
- `email: 1` (unique)
- `role: 1`
- `addresses.salon.coordinates: "2dsphere"` (géospatial)

#### 2. **Service.js** - Modèle services (DÉJÀ PARFAIT !)
**Champs existants:**

**Index existants:**

- `category: 1`
- `isActive: 1`
- `keywords: 1`
- `likes: -1`

## 🚨 POINTS CRITIQUES IDENTIFIÉS

### **1. SPÉCIALITÉS - LIMITATION MAJEURE**
- **Actuel:** `speciality: String` (UNE SEULE spécialité)
- **Besoin:** Tableau de spécialités avec niveaux d'expertise
- **Impact:** Algorithme de recherche limité

### **2. CRÉNEAUX - ABSENCE TOTALE**
- **Actuel:** `workingHours: Object` (structure simple)
- **Besoin:** Système de créneaux avec disponibilité
- **Impact:** Réservations sans vérification des créneaux

### **3. PRIX DYNAMIQUES - ABSENCE TOTALE**
- **Actuel:** `price: Number` (prix fixe dans Service)
- **Besoin:** Prix variables par créneau et lieu
- **Impact:** Pas de gestion des tarifs dynamiques

### **4. GÉOLOCALISATION - PARTIELLEMENT PRÉSENTE**
- **Actuel:** `coordinates: {lat, lng}` dans addresses
- **Besoin:** Optimisation pour recherche géospatiale
- **Impact:** Recherche par distance limitée
