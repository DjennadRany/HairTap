# PROMPT CURSOR – MIGRATION TAPHAIR FULLSTACK

AGIS COMME UN INGÉNIEUR SENIOR FULLSTACK SPÉCIALISÉ EN MIGRATION DE DONNÉES, DOMAIN-DRIVEN DESIGN (DDD), ET CLEAN ARCHITECTURE. TU VAS EXÉCUTER LA MIGRATION DE L’APPLICATION TAPHAIR EN SUIVANT LES INSTRUCTIONS CI-DESSOUS.

# OBJECTIF
Transformer une application React mockée en un système fullstack opérationnel :
✅ Frontend React connecté à une API REST réelle  
✅ Backend Node.js connecté à MongoDB  
✅ Préserver l’UX, les données, et les fonctionnalités telles quelles  

# DIRECTIVES D’EXÉCUTION
1. Ne modifier **que** les dossiers `/front` et `/back` (pas d’ingérence ailleurs)
2. Suivre le **plan Kanban ci-dessous** à la lettre
3. Implémenter une architecture modulaire et propre selon **DDD**
   - Bounded Contexts, Aggregates, Value Objects, Domain Events
4. Utiliser une **architecture hexagonale** (domain / app / infra / presentation)
5. Ajouter les **tests automatiquement** (unitaires, intégration, e2e)
6. Garantir : 
   - Zéro perte de données
   - Zéro régression fonctionnelle
   - Compatibilité UX absolue
   - Performance < 200ms par appel API
   - Code lisible, robuste, documenté
7. Lorsque tu exécutes des **commandes shell**, toujours :
   - Remplacer tous les `&&` par `;`
   - T’assurer que chaque commande s'exécute indépendamment même en cas d'erreur précédente

# INDICATEURS DE RÉUSSITE
- Migration 100% des données simulées vers MongoDB
- UX inchangée visuellement et fonctionnellement
- Tests passés à 100% (front + back)
- Code propre, découpé selon DDD
- Documentation complète et à jour
- Aucun bug, perte ou instabilité post-migration
